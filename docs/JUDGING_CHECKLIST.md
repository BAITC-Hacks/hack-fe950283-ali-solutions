Основание: предоставленный пользователем текст разделов **7. Must have, 8. Опционально, 9. Ограничения, 10. Артефакты**, примечание организаторов и рубрика 25/25/25/15/10. Это проверка покрытия полученного фрагмента ТЗ; остальные разделы не предоставлены. Наличие функции, автоматическая проверка и фактическая демонстрация на другом компьютере — отдельные статусы.

Два независимых процесса в сохранённой приёмке завершились за 24.8 и 22.5 с; пять CSV идентичны. В коде аналитики нет списков «правильных» gid; примеры в демо выбираются из рассчитанных результатов.

## Ограничения раздела 9

| Требование | Покрытие |
|---|---|
| Нет хардкода ответов / чёрного ящика | Формальные правила и вычисляемые признаки; случайные состояния фиксированы. Gid используется как идентификатор, не как условие роли. Дополнительная модель не определяет роли. |
| Нет внешнего обогащения | Аналитика читает только предоставленные parquet; внешние персональные атрибуты не создаются. |
| Приватность и осторожность | Полные обезличенные gid остаются строками в UI/API. Роли — гипотезы; назначение операций и виновность не выводятся. Внешний LLM получает ограниченные факты только при явном включении; передача провайдеру описана в README. |
| Локальная инфраструктура, без GPU/платных сервисов | Python/NetworkX и встроенный Cytoscape. AI_ENABLED=false оставляет локальные функции доступными. Установка пакетов требует сети или подготовленных wheel-пакетов; работа уже установленного приложения — нет. |
| Объяснимый приоритет | Видны компоненты, веса, seed_factor, normalizer и основания why; тест восстанавливает формулу и сверяет CSV/HTML/API. |
| ≤300 секунд | Выполнено в двух независимых процессах на текущем Windows-компьютере; не проверено на отдельном обычном/слабом ноутбуке. |
| Масштабирование до ~1 млн | README: батчевые агрегаты, компактный backend, приближённая центральность, ограниченные обходы и серверные подграфы. Реализация на таком объёме не заявляется. |

## Автоматическая приёмка

Команда PowerShell:

```powershell
.\.venv\Scripts\python.exe scripts/verify_acceptance.py --timeout 120
```

Отчёт [acceptance.json](acceptance.json) содержит точные времена, run_id и SHA-256 пяти CSV. Скрипт запускает тесты и два отдельных процесса расчёта из исходных parquet в независимых временных каталогах. По достижении таймаута процесс останавливается, статус timeout не считается успехом. Поля времени manifest не сравниваются как детерминированный результат.

| Требование | Реализация | Проверка |
|---|---|---|
| Лаг 1–2 дня, полное окно, тот же день отдельно | features._fast_forward, temporal | До входа, тот же день, лаги 1/2/3, переход месяца, частичные суммы, конец периода, отсутствие окна |
| Всплески, синхронность и повторные маршруты | features._incoming_burst, temporal, AnalysisService | Календарный знаменатель с тихими днями, пороги, равные пики, пустое/короткое окно; повторные цепочки на разных датах; доступность признаков в справке |
| Граница depth=4 только как подсказка | roles, truncation | Нет terminal у depth=4 и seed; отсутствие sklearn и недостаточная выборка не блокируют расчёт |
| Изоляты и небольшие наборы | priority, clusters, resilience | Нулевые scores, 1 узел без рёбер, self-loop; результаты проходят валидацию |
| Восстановление priority | priority, AnalysisService | Взвешенная сумма × seed_factor / normalizer; совпадение HTML/ядра и top/CSV |
| Проверка входа | load.sanity_check | Дубли gid/пар, endpoints, суммы/count, NaN, даты, float gid отклоняются |
| Общие получатели и направленные пути | AnalysisService | Все источники, direct/reachable, cutoff, лимиты, дубли, неизвестные gid, точные длинные ID |
| Вопрос «кто собирает с этих пяти» | assistant._ask_offline | Совпадение всех пяти; исключение получателя лишь от четырёх; явно запрошенные косвенный и «≥2» режимы; неизвестные/повторные gid, лимиты 20/4 |
| Tool loop и fallback | assistant | Mock HTTP, неизвестные tools/аргументы, недействительные факты/gid, malformed JSON/структура ответа, timeout/disconnect, бюджет, валидный ограниченный JSON |
| Локальный HTTP и экспорт | serve | Query/ask без ключа, 400/409, attachment headers, совпадение CSV-байтов, Markdown узла |
| Целостная публикация | pipeline.run | Ошибка записи сохраняет предыдущий результат, lock снимается |
| Повторяемость и скорость | verify_acceptance.py | Два новых процесса, одинаковый run_id и пять CSV; внешний лимит этапа 120 с, сравнение с 300 с |
| Самодостаточный HTML | viewer | CSS/JS встроены, маркеры заменены, внешних script src нет; точные суммы и scores |


Последний сохранённый результат в acceptance.json: **64 теста пройдены за 43.93 с**. Два процесса завершились за **24.8 с** и **22.5 с** (включая запуск Python). Все пять CSV совпали побайтно; run_id: 70f951b546638c1f3a3a. Обязательные проверки экспорта пройдены. Это измерение на данном Windows-компьютере, не гарантия времени для другого оборудования. При изменении исполняемого кода, ресурсов или зависимостей run_id меняется; новый результат следует сверять с актуальным acceptance.json.

### Новое изолированное окружение

[CLEAN_INSTALL_CHECK.json](CLEAN_INSTALL_CHECK.json) фиксирует отдельный venv без системных пакетов на том же Windows-компьютере. Первая установка зависимостей достигла лимита 90 с и была остановлена. После проверки оказалось, что нужные пакеты уже установлены: `pip check` и импорты pandas/pyarrow/networkx/numpy/scipy/sklearn прошли. Без повторной установки в этом окружении выполнен pipeline из исходных parquet: **28.6 с**, 2 248 узлов, 50 кластеров, 50 позиций топа, 14 успешных проверок. Лимит расчёта — 120 с. Хеши трёх CSV совпали с финальной сборкой; сравнение записано в отчёте.

Это подтверждает работоспособность нового изолированного окружения на текущем компьютере. Не подтверждает успешный выход первоначальной команды pip, установку без сети или запуск на отдельно подготовленной чистой ОС. HTML этого прогона не использовался для финальной проверки интерфейса, поскольку UI дорабатывался параллельно.

## Браузерные сценарии

Проверено через локальный сервер с AI_ENABLED=false, в браузере Codex:

- Главная карта, поиск полного ID, карточка из топа и переход в окружение узла.
- Новый вид первого шага, скрытие общей карты в этом режиме, закрытие панели анализа.
- «Пути от seed»: у первого узла топа показаны 4 направленных пути.
- Три источника: 2 общих прямых получателя и 23 общих достижимых узла при глубине 4.
- Экспорт CSV: браузер выдаёт событие скачивания; содержимое и заголовки проверяются отдельно через HTTP.
- Шаблонный ассистент без внешнего ключа, факты функций и журнал вызовов.
- Пустой результат поиска, фильтры и интерфейс шириной 390 px без горизонтального переполнения.
- Консоль проверенных страниц без ошибок JavaScript.

### Компактный интерфейс: финальная проверка

- Inter загружен из встроенного WOFF2; SVG-кнопки имеют доступные имена и подсказки. Три экспорта различаются именами файлов для screen reader.
- Ассистент открывается справа внизу; справка кнопкой относится к выбранному узлу. Факты и журнал раскрываются отдельно, история сохраняется при сворачивании.
- Проверены карточки координатора, консолидатора, depth=4 и изолята; новые всплески и структурные признаки доступны в раскрываемом блоке.
- Переключение окружения 1/2 шага, экономного режима, масштабирование; изолят отображает один узел. Все 2 248 узлов доступны в полной карте.
- Диалог и мобильные фильтры проверены при 390×844: горизонтального переполнения нет, исходный размер браузера восстановлен.
- Локальный ответ, три download-события CSV, направленные пути, прямые общие получатели и точные gid; консоль без ошибок JavaScript.
- Оптимизации и пределы замеров описаны в [VIEWER_PERFORMANCE.md](VIEWER_PERFORMANCE.md). Проверка не является измерением FPS на слабом устройстве.

## Ограничения проверки

- Внешний LLM API не вызывался. Успешный mock tool loop не подтверждает совместимость с любым провайдером.
- Прямое открытие file:// заблокировано политикой браузерного инструмента. Обход не выполнялся; проверены встроенные ресурсы и работа того же HTML через HTTP. Физическое отключение сети не проверялось.
- Linux, производительность на миллионах узлов и реальная точность ролей не проверялись. Подтверждённой разметки ролей нет.
- Отдельная чистая ОС, физическое слабое устройство и выступление перед жюри не проверялись. Проверены новое изолированное Python-окружение на текущем Windows и браузерные сценарии; узкий экран не заменяет слабое оборудование.
- Воспроизводимость заявлена для закреплённого окружения; изменение версий библиотек может изменить кластеры.
