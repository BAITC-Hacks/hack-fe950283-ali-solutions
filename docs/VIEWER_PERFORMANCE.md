# Отрисовка MoneyGraph

## Причина изменений

`serve.py` один раз запускает расчёт, затем отдаёт готовый HTML через стандартный `ThreadingHTTPServer`. Перезагрузчика кода, HMR и отдельного dev-режима здесь нет. В браузере используется локальная Cytoscape.js 3.34.3; раскладка основной сети заранее вычислена Python.

Основная карта содержит все **2 248 узлов и 3 119 направленных рёбер**. Размер текущего набора сохранён: оптимизация не исключает узлы из поиска, аналитических запросов или общей карты.

## Что изменено

- Canvas использует `pixelRatio: 1`: на экранах с высокой плотностью пикселей требуется меньше пикселей для отрисовки. Возможна меньшая резкость графа; HTML-интерфейс и SVG-иконки сохраняют штатную резкость экрана.
- Основные рёбра и стрелки имеют непрозрачные приглушённые цвета. При выделении пути или окружения остальные рёбра затемняются цветом, без массовой полупрозрачности стрелок.
- Значение подписи записывается только при изменении. Выделение и изменение подписей объединены через `cy.batch()`.
- При выборе узла в окружении скрытая основная карта не получает полную операцию выделения.
- Экземпляр Cytoscape для окружения переиспользуется; повторное создание графа одним нажатием удалено.
- Новое движение камеры отменяет предыдущую анимацию, вместо накопления очереди.
- Уведомления об изменении размера объединяются в один кадр. Панели анимируют прозрачность и смещение; ширина графа не анимируется покадрово.
- Встроенный Inter не требует сети. После готовности шрифта подписи canvas обновляются один раз.

Опции кеширования viewport и скрытия рёбер во время движения присутствовали ранее и сохранены. Их влияние отдельно не измерялось. Основание для выбора renderer-настроек: [официальная документация Cytoscape.js](https://js.cytoscape.org/#performance).

## Режимы

| Настройка | Стандартный | Экономный |
|---|---|---|
| Полнота основной карты | Все узлы и рёбра | Все узлы и рёбра |
| Pixel ratio canvas | 1 | 1 |
| Подписи основной карты | Выбранный узел, окружение и выбранный режим подписей | Выбранный узел |
| Переход камеры к узлу | 220 мс | Мгновенный |
| Окружение | Кривые рёбра; суммы со второго шага | Прямые рёбра без подписей сумм |
| Аналитика, поиск, экспорт | Полный набор | Полный набор |

Экономный режим по умолчанию включается при сообщаемых браузером ≤4 логических процессорах либо ≤4 ГБ памяти. Это эвристика, не измерение производительности устройства. Переключатель в разделе «Отрисовка» сохраняет явный выбор в `localStorage`. При недоступном хранилище просмотр продолжает работать. Кнопка подписей возвращает стандартный режим.

`prefers-reduced-motion: reduce` отключает CSS-анимации и движение камеры независимо от выбранного режима. Окружение в обоих режимах показывает до 24 крупнейших контрагентов на сторону и шаг, с явным счётчиком остальных. Эта существующая граница отображения окружения не ограничивает общую карту или аналитические запросы.

## Измеренная локальная операция

Проведён отдельный микробенчмарк в Node.js на фактических 2 248 узлах и 3 119 рёбрах из `out/index.html`. Использованы тот же локальный файл Cytoscape.js, `headless: true`, `styleEnabled: true` и стиль `label: data(lbl)`.

После одного прогрева 20 раз выполнялся одинаковый проход по узлам: короткий ID для первых 25 по рангу, пустая строка для остальных. Первый вариант всегда вызывал `el.data('lbl', next)`, второй — только если `el.data('lbl') !== next`. Каждый проход выполнялся внутри `cy.batch()`; время измерялось `performance.now()`.

| Вариант | Время 20 проходов | Записи в data |
|---|---:|---:|
| Всегда перезаписывать подпись | 290,9 мс | 44 960 |
| Записывать только изменённую | 75,7 мс | 0 |

Это один локальный замер обработки неизменившихся подписей. Он не включает canvas, браузерную компоновку или перемещение графа; его нельзя интерпретировать как ускорение FPS интерфейса. При реальном выборе узла часть подписей меняется и записи остаются необходимыми.

## Проверка интерфейса и границы вывода

В браузерной проверке текущей сборки подтверждены: загрузка Inter, ширина canvas **682 пикселя** при CSS-ширине **682 пикселя**, все **2 248 узлов** на общей карте, окружение **36 узлов** в проверенном сценарии двух шагов, работа масштаба и переключателя экономного режима. Ошибок JavaScript в проверенных сценариях не обнаружено.

Отдельного измерения FPS, профиля длительных кадров и испытания на физическом слабом устройстве не было. Поэтому подтверждены конкретные сокращения лишних операций и работоспособность режимов; численное ускорение всего интерфейса не заявляется.
