# Демо за пять минут

До выступления установите зависимости из `requirements.txt` (точные версии — `requirements.lock`, Python 3.12+), проверьте `python -m pytest -q` и откройте терминал в проекте. Интернет и ключ LLM для сценария не требуются.

| Время | Действие | Что подтверждает |
|---|---|---|
| 0:00–0:35 | `python run.py`, показать проверки и время. Открыть `out/index.html` или заранее запущенный `python serve.py` | Воспроизводимость, все обязательные CSV, расчёт <5 минут |
| 0:35–1:00 | Обзор сети, переключить цвет на кластеры, открыть «Качество» | Направление, роли, 2 248 узлов, точные схемы и ограничения данных |
| 1:00–2:00 | Найти `100000008603629100`, открыть «Связи узла» | Координатор: 19 плательщиков, 61 получатель, 19 связей с ключевыми узлами; сравнить с порогами 5/10/5 |
| 2:00–2:45 | Найти `100000003115284100`, прочитать вход/выход и роль | Консолидатор: 8 плательщиков, 2 получателя, видимый пропуск около 24%; показать численное обоснование |
| 2:45–3:25 | Найти `100000003985389100` | Обрыв четвёртого колена: 16 поступлений, P(передаёт)≈0.99, исходящие неизвестны; нулевой выход не трактуется как сток |
| 3:25–4:10 | Добавить 2–3 клиента на «Проверку», оставить заметку, скачать CSV и справку | Готовый рабочий результат аналитика, конкретные следующие запросы |
| 4:10–4:40 | Открыть «Устойчивость»: сравнить удаление 20 приоритетных узлов и 20 seed | Приоритет перемещается с известных участников к точкам структуры; честно показать сравнение с оборотом |
| 4:40–5:00 | В ассистенте выбрать готовый вопрос про общих получателей; завершить ограничениями | Ответ по графу со ссылками, работа без внешней модели |

Если жюри называет произвольный gid: нажмите `/`, вставьте идентификатор, Enter, затем «Связи узла». В карточке есть правило, численные признаки, вклад в приоритет и запросы данных. При активных фильтрах скрытый узел открывается со сбросом фильтров и уведомлением.

Если порт 8000 занят: `python serve.py --port 8765`. Если локальный сервер недоступен, откройте `out/index.html`: граф, карточки, топ, список проверки и скачивание файлов работают автономно; ассистенту нужен сервер.

Обязательно проговорите: ground truth ролей отсутствует; скор не является вероятностью виновности; данные не содержат внешних входящих, остатков, наличных и межбанка. Конкретные названия и назначения организаций не устанавливаются.
